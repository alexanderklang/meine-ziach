MEINE ZIACH – Version 0.1

Enthalten: index.html, app.js, manifest.webmanifest.

Zum Testen: Dateien gemeinsam auf einen HTTPS-Webspace hochladen und index.html auf dem iPhone in Safari öffnen. Über Teilen > Zum Home-Bildschirm hinzufügen installieren.

Alternativ am Computer lokal mit einem einfachen Webserver testen (z. B. python3 -m http.server 8000).

WICHTIG: Daten werden nur im lokalen Browser-Speicher gespeichert. Regelmäßig Backup als JSON exportieren. Kein Cloud-Sync. Für die zuverlässige Offline-Nutzung ist in einer nächsten Version ein Service Worker erforderlich.
